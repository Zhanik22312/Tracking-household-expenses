# Tracking-household-expenses
Console home expense tracker written in Python with JSON data persistence, unit tests, and GitHub Actions CI workflow.
# Home Expense Tracker

Простая консольная программа на Python для учета и анализа домашних расходов с автоматическим сохранением данных в формат JSON и интегрированным CI/CD пайплайном через GitHub Actions.

## Функциональные возможности

- **Добавление расходов:** Запись суммы, категории и даты операции.
- **Хранение данных:** Автоматическая запись и чтение данных из локального файла `expenses.json`.
- **Аналитика:** Подсчет общих расходов, фильтрация по категориям и временным периодам.
- **Генерация отчетов:** Вывод итоговой статистики в консоль.
- **Тестирование:** Покрытие базовых функций расчетной логики модульными тестами (`unittest`).
